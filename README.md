# ÌTURA Coffee & Comfort

**Coffee. Comfort. Community.**

ÌTURA is a premium café website concept inspired by the warmth, comfort, and community of Abuja's coffee culture. The project combines an inviting visual identity with a responsive layout and reusable UI components.

## Project Status

**In development**

Current features:
- Homepage hero and brand introduction
- Menu highlights with sample items and prices
- Gallery preview with café photography
- Shared responsive navigation
- Warm, café-inspired typography and colour palette

Planned features:
- Dedicated menu, gallery, events, about, and contact pages
- Interactive gallery filtering and lightbox
- Event RSVP and contact forms
- Responsive refinements, accessibility checks, and deployment

## Tech Stack

- Next.js 14 with the App Router
- React and TypeScript
- Tailwind CSS
- Git and GitHub for version control
- Netlify as the planned deployment platform

## Getting Started

### Requirements

Install Node.js and npm before running the project.

### Installation

Clone the repository:

```bash
git clone https://github.com/Yomi-X/ITURA.git
cd ITURA
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed in your terminal, usually `http://localhost:3000`.

### Available Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — serve the production build
- `npm run lint` — run the configured lint checks
