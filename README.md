# ÌTURA Coffee & Comfort

A premium, responsive cafe website template inspired by the warmth of Abuja's coffee culture.

**Brand tagline:** Coffee. Comfort. Community.

## Project goals

- Build a responsive multi-page website.
- Use Next.js App Router, TypeScript, and Tailwind CSS.
- Create reusable UI components.
- Practice Git branching, merging, and version control.
- Prepare the site for deployment on Netlify.

## Development status

Initial repository setup. Next.js application setup is the next milestone.

## Reference material

The `reference/` folder contains an existing standalone HTML website used for studying layout and styling techniques. It is not part of the ÌTURA website itself.
